# VoxLog → Cognitive OS Bridge

This document defines how a VoxLog voice capture becomes a canonical Cognitive OS life entry. The bridge is an adapter contract, not a new VoxLog client, bot, server, or UI. It assumes that VoxLog can provide a transcript or exported text plus capture metadata. The adapter may be implemented as an export reader, folder watcher, webhook consumer, or manual handoff.

The bridge has one non-negotiable rule: **never discard the original voice capture or transcript when structured fields are extracted**. The normalized capture carries the raw text and provenance forward; the Cognitive OS pipeline then adds categorization and writes the durable copies.

## Data flow

```text
VoxLog recording/transcript
        ↓
normalized capture JSON
        ↓
voice-to-sqlite.py
        ├── Gemini Flash categorization, when explicitly enabled
        ├── entry.schema.json validation
        ├── SQLite operational record
        └── JSONL backup line
        ↓
Git commit + weekly markdown review
```

## Field mapping

The left-hand names are the recommended adapter names. VoxLog exports may use different names; map them once at the edge and keep the Cognitive OS names stable.

| VoxLog data | Cognitive OS field | Mapping rule |
| --- | --- | --- |
| Transcript text, transcription body, or manually corrected transcript | `raw_text` | Preserve the complete source text without summarizing it. This is the replayable input for extraction. |
| Recording time or event time | `timestamp` | Convert to an ISO 8601 date-time with an explicit timezone. Prefer when the observation happened; use capture time only when event time is unavailable. |
| Recording ID, file ID, or stable VoxLog URL | `source_ref` | Store a stable reference when available. Do not embed credentials or expiring private tokens in the entry. |
| Constant adapter label | `source` | Set to `voxlog`. |
| Domain/category selected by Gemini Flash or the user | `domain` | Use an active domain name from `domain.schema.json`. If uncertain, use `uncategorized` and review it rather than guessing. |
| Measurement, count, duration, amount, or qualitative observation | `value` | Preserve the observed value. Numeric values should remain numeric; qualitative observations may remain strings or structured JSON. |
| Unit spoken or implied by the capture | `unit` | Normalize only unambiguous units, such as `minutes`, `hours`, `steps`, or `count`. Use `null` when no unit applies or the transcript is uncertain. |
| Contextual transcript or extracted explanation | `notes` | Keep concise context here, but do not use it as a replacement for `raw_text`. A local fallback uses the transcript as notes. |
| Explicit mood or model-derived score | `sentiment` | Use a number from `-1` to `1`, or `null` when unsupported. Do not infer a score from a single ambiguous phrase. |
| Explicit self-report such as “energy was 7” | `energy` | Use an integer from `1` to `10`, or `null` when absent. Do not turn speaking volume or model confidence into energy. |
| VoxLog/extraction event identifier | `id` | Prefer a stable UUID generated by the bridge. Reuse the same ID when replaying the same capture so duplicate ingestion can be detected. |
| Extraction engine and version | `extraction_method` | Use `gemini-flash` for an explicit model call, `local-fallback` when no model is used, or `manual` when the user supplies the structured fields. |
| Time the canonical entry was written | `created_at` | Set by the pipeline, not by the transcript. This distinguishes event time from ingestion time. |

## Normalized capture contract

The bridge should hand the pipeline a single JSON object. The minimum useful object is:

```json
{
  "raw_text": "Walked for 30 minutes after lunch; I feel more focused.",
  "timestamp": "2026-08-26T12:30:00+05:30",
  "source": "voxlog",
  "source_ref": "voxlog://recording/2026-08-26/1230"
}
```

A capture that already contains structured fields may include them in the same object:

```json
{
  "id": "8c4f5d42-4f91-4b11-8ad6-5e6b4f6c1b23",
  "raw_text": "Walked for 30 minutes after lunch; I feel more focused.",
  "timestamp": "2026-08-26T12:30:00+05:30",
  "source": "voxlog",
  "source_ref": "voxlog://recording/2026-08-26/1230",
  "domain": "health",
  "value": 30,
  "unit": "minutes",
  "notes": "Walked after lunch and felt more focused afterward.",
  "sentiment": 0.7,
  "energy": 8
}
```

The bridge should not force a value into a capture that contains no measurable observation. In that case, retain the transcript as `raw_text` and `notes`, use a reviewable domain such as `uncategorized`, and leave `sentiment` and `energy` as `null`.

## Handoff to the reference pipeline

Save one normalized capture object to a file and pass it to the reference importer:

```bash
python3 pipelines/voice-to-sqlite.py \
  --input exports/voxlog/capture.json \
  --db data/cognitive.db \
  --jsonl data/entries.jsonl \
  --categorizer local-fallback
```

To use the Gemini Flash adapter, select it explicitly and provide the endpoint and credential through the process environment rather than storing them in a capture or Git:

```bash
GEMINI_FLASH_ENDPOINT="https://your-adapter.example/v1/categorize" \
GEMINI_FLASH_API_KEY="<provided-out-of-band>" \
python3 pipelines/voice-to-sqlite.py \
  --input exports/voxlog/capture.json \
  --db data/cognitive.db \
  --jsonl data/entries.jsonl \
  --categorizer gemini-flash
```

The endpoint is intentionally provider-agnostic. A real deployment should adapt its VoxLog export and model API to this contract rather than changing the canonical schema for each vendor.

## Idempotency and failure handling

The bridge should be safe to replay. A stable `id` is the primary deduplication key. Before writing, check whether the ID already exists in SQLite or the JSONL archive. If it exists with the same canonical JSON, treat the replay as an idempotent success; if it differs, stop and report a provenance conflict instead of overwriting history.

A failed transcription or categorization must not be silently dropped. Keep the original reference and raw text in a quarantine or retry location, then rerun extraction later. If Gemini Flash is unavailable, the reference pipeline’s deterministic fallback creates a valid entry with uncertain fields as `null`; a later human review can add a new corrected entry or perform an explicit migration.

The importer writes SQLite and JSONL together and the [backup contract](../schemas/backup.contract.md) requires the JSONL change to be committed to Git. The bridge itself must never commit audio, API keys, or other secrets. If the recording is retained outside Git, `source_ref` should identify the protected storage location without exposing its credentials.

## Verification checklist

A VoxLog adapter is connected correctly when a test recording produces a normalized JSON object, the object retains `raw_text` and a timezone-aware `timestamp`, `voice-to-sqlite.py` writes one validated SQLite row and one JSONL line, `jsonl-backup.py` accepts the backup, and a weekly report includes the resulting domain and notes. The adapter should also be tested with an intentionally incomplete transcript to confirm that uncertainty is preserved instead of fabricated.
