## Honest implementation boundary

The repository now has a functional local reference application and executable contracts, but it does not claim to be a production SaaS product. Local authentication still uses a role header, the agent service uses a deterministic fallback unless configured with `AGENT_SERVICE_URL`, and the graph/vector adapters are local compatibility implementations rather than live Kùzu/LanceDB deployments. VoxLog, Telegram, Logseq, Gemini Flash, and Streamlit remain integration seams or documented adapters because their external credentials and provider-specific contracts are not available in the clean-room environment.
